## A proposta

O Blabry nasceu como um app estilo Twitter — só postagens e perfil, sem chat. Com o tempo, a ideia cresceu. Hoje é uma plataforma mais completa, com chat em tempo real via WebSockets, feed de publicações, sistema de seguidores e perfis de usuário.

A motivação para reimaginar o projeto foi direta: perdi uma vaga por não conhecer WebSockets. Em vez de só estudar o conceito, decidi construir uma rede social inteira com esse recurso no centro. O resultado é o Blabry que existe hoje.

O projeto pode crescer muito além do que é agora — a arquitetura foi pensada para escalar.
